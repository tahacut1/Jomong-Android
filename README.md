# Jomong Android Clean

A clean Kotlin/Android Canvas prototype for Android.

- Package: `com.example.jomongpro`
- compileSdk/targetSdk: 35
- minSdk: 23
- Java/Kotlin target: 17
- Designed to build with Gradle 8.9 on GitHub Actions.

The GitHub Actions workflow builds `app-debug.apk` and uploads it as an artifact.
