# Jomong Android Pro — GitHub Actions

این پروژه برای ساخت APK با GitHub Actions تنظیم شده است.

## ساخت APK با یک کلیک

1. کل محتویات این ZIP را داخل یک Repository جدید در GitHub قرار بده.
2. وارد تب **Actions** شو.
3. از سمت چپ **Build Jomong APK** را انتخاب کن.
4. روی **Run workflow** بزن.
5. بعد از اتمام، وارد اجرای سبز رنگ Workflow شو.
6. در پایین صفحه، بخش **Artifacts**، فایل **Jomong-Pro-APK** را دانلود کن.
7. فایل `app-debug.apk` را روی گوشی شیائومی نصب کن.

### نکته
این خروجی یک **debug APK** است و برای تست و نصب شخصی مناسب است. برای انتشار در Google Play بهتر است نسخه release با امضای رسمی ساخته شود.
